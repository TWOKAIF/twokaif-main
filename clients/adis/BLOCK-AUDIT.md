# Адис Маммо — поблочный аудит сайта

Обновлено: 2026-07-20

Этот файл — рабочий журнал последовательного разбора XL-версии во Framer. Решения заносятся сюда только после обсуждения с Русланом. Изменения во Framer выполняются отдельным шагом после подтверждения.

## Сквозная система XL

### Сетка и вертикальный ритм — утверждено

- Рабочий размер XL: `1440 px`.
- Внешние горизонтальные поля: по `30 px`.
- Рабочая ширина: `1380 px`.
- Основная сетка: четыре равные колонки по `345 px`.
- Все внутренние расстояния собирать на базовом шаге `8 px`.
- Основная шкала интервалов: `8 / 16 / 24 / 32 / 48 / 64 / 96 / 120 px`.
- От сервисной строки каждого номерного блока до главного контента: `96 px`.
- Между соседними крупными блоками: `120 px`.
- Точные расстояния внутри отдельных композиций могут отличаться только там, где они уже специально утверждены и имеют визуальную функцию.
- При переносе решений во Framer не подгонять каждый блок произвольными значениями: сначала использовать общую шкалу, затем проверять оптический баланс на `1440 × 900`.

### Типографическая шкала — утверждено

- Векторный титул `АДИС МАММО` в Hero сохранить без изменений.
- `Druk Wide Cyr Medium`, `50 px / 50 px`: `СМОТРЕТЬ`, главная фраза в `//ПОЗИЦИЯ`, `ПРЯМАЯ СВЯЗЬ`.
- `Druk Wide Cyr Medium`, `30 px / 34 px`: главные факты в `//ОБ АДИСЕ` и крупная расшифровка контактов.
- `Inter Tight Semibold`, `28 px / 30 px`: заголовки медиакарточек.
- `Inter Tight Medium`, `24 px / 28 px`: заголовки аккордеонов.
- `Inter Tight Medium`, `20 px / 26 px`: крупный вторичный текст.
- `Inter Tight`, `18 px / 24 px`: имена и типы событий.
- `Inter Tight Semibold`, `16 px / 20 px`: ссылки.
- `Inter Tight Semibold`, `15 px / 18 px`: кнопки.
- `Inter Tight`, `14 px / 18 px`: технические подписи заглушек и футер.
- `Inter Tight`, `12 px / 16 px`: сервисные строки секций.
- `Druk Wide Cyr` использовать только для крупных смысловых акцентов. Кнопки, ссылки, аккордеоны, имена, подписи и служебные тексты — только `Inter Tight`.

### Система медиазаглушек — утверждено

- Общий фон: `#151515`.
- Общий радиус: `16 px`.
- Не использовать рамку и тень.
- Подпись выровнять строго по центру.
- Шрифт подписи: `Inter Tight Medium`, `14 px / 18 px`, цвет `#808080`.
- У пустой заглушки не должно быть hover, курсора-ссылки, стрелки или другого ложного признака интерактивности.
- Подпись должна описывать реальное назначение места:

```text
ФОТО / ВИДЕО · 1200 × 690 PX
ФОТО СОБЫТИЯ · 1600 × 1000 PX
ФОТО / ВИДЕО СО СЦЕНЫ · 1600 × 1000 PX
ФОТО · 325 × 486 PX
ВИДЕО · 60–120 СЕК
```

- В коллаже `//ПОЗИЦИЯ` сохраняются разные размеры карточек, но оформление и типографика заглушек остаются общими.
- Исключение — карточки логотипов тикера: радиус `10 px`, потому что это отдельная визуальная система.

### Система движения — утверждено

- Hover кнопок и ссылок: `320 мс`.
- Раскрытие аккордеона: `420 мс`.
- Появление секции или фотографии: `600 мс`.
- Задержка между последовательными появлениями фотографий: `80 мс`.
- Общее плавное замедление: `cubic-bezier(0.22, 1, 0.36, 1)`.
- Тикер движется отдельно: строго линейно, полный цикл `48 секунд`.
- Не использовать пружинные анимации, увеличение карточек и резкие рывки.
- Точки показывать только там, где пользователь действительно переключает несколько материалов.
- Стрелка допустима только у рабочей ссылки или доступного видео.
- У пустых заглушек не должно быть интерактивных эффектов.

### Навигация XL — утверждено

Основные пункты меню:

```text
СМОТРЕТЬ
ОБ АДИСЕ
ПОЗИЦИЯ
КОНТАКТЫ
```

- Переименовать старый пункт `МАТЕРИАЛЫ` в `СМОТРЕТЬ`, чтобы не смешивать публичный медиаблок с отдельным пакетом для организаторов.
- `СМОТРЕТЬ` ведёт строго к сервисной строке блока `01`.
- `ОБ АДИСЕ` ведёт строго к сервисной строке блока `02`.
- `ПОЗИЦИЯ` ведёт строго к сервисной строке блока `03`, а не к хвосту аккордеонов предыдущего блока.
- `КОНТАКТЫ` ведёт строго к сервисной строке блока `04`.
- Верхняя кнопка `СВЯЗАТЬСЯ` ведёт к тому же началу блока `04`.
- Нижний пункт `ОРГАНИЗАТОРАМ` позже ведёт на отдельную страницу пакета для организаторов.
- При переходе по любому пункту сервисная строка нужного блока должна быть видна у верхней границы рабочей области; нельзя приземлять пользователя в середину предыдущего или следующего блока.

## Hero / титульник

### Решение

- Сохраняем текущий каркас: сервисная шапка, крупное имя `АДИС МАММО`, роли и форматы, один большой медиаблок.
- Не добавляем на первый экран регалии, биографию, достижения или дополнительный слоган.
- Позиционирование первого экрана: `ВЕДУЩИЙ` / `КОМИК`; в центре — `ЧАСТНЫЕ СОБЫТИЯ / КОРПОРАТИВНЫЕ МЕРОПРИЯТИЯ / СТЕНДАП`.
- `КРЕАТОР` на первом экране пока не используем.
- До появления подходящей обложки оставляем заглушку.
- Анимацию финализируем только с реальным изображением: имя, роли и фото должны появляться одной спокойной сценой без конкурирующих эффектов.

### Что уже есть

### Что запросить у Адиса

- 3–5 горизонтальных фотографий в оригинальном качестве, желательно от 2400 px по ширине.
- Кадры без наложенных надписей и крупных чужих логотипов, с запасом по краям для кадрирования.
- Если есть — спокойный горизонтальный видеопортрет на 5–10 секунд, Full HD или 4K, без титров и музыки.
- Точную ссылку на личный Telegram для верхней кнопки `СВЯЗАТЬСЯ`.
- Подтверждение географии работы: только Москва или возможен выезд.
- Подтверждение финальной формулировки профессии: `ведущий и комик`.

### Статус

Смысл и композиция утверждены. Реальное фото/видео и ссылки ожидаются от Адиса. Во Framer на этом этапе ничего менять не нужно.

## 01 //СМОТРЕТЬ / ФОТО И ВИДЕО

### Утверждённая задача блока

После титульника показать Адиса в работе: не повторять позиционирование и регалии, а дать быстро почувствовать его подачу в разных форматах.

### Утверждённая композиция

- Одна большая ведущая карточка `ШОУРИЛ`.
- Ниже три равные карточки: `ЧАСТНЫЕ СОБЫТИЯ`, `КОРПОРАТИВНЫЕ МЕРОПРИЯТИЯ`, `СТЕНДАП`.
- Из двух вводных фраз оставить только `НЕСКОЛЬКО МИНУТ, ЧТОБЫ ПОЧУВСТВОВАТЬ ПОДАЧУ`.
- Точки-переключатели показывать только в карточках, где действительно будет несколько материалов.
- Дуэты с Ксенией Собчак и Натали Веда здесь не дублировать — оставить для блока `СЦЕНА И ДУЭТЫ`.

### Материалы, которые уже есть

- `ШОУРИЛ` — горизонтальный ролик `1. АДИС МАММО ШОУРИЛ. (легкий).mp4`, 03:56, 1920 × 1080.
- `ЧАСТНЫЕ СОБЫТИЯ` — несколько горизонтальных свадебных и частных роликов; основным кандидатом выбран ролик про свадьбу на крыше.
- `КОРПОРАТИВНЫЕ МЕРОПРИЯТИЯ` — горизонтальный ролик с бизнес-мероприятием на 6000 человек и вертикальный ролик с ПМЭФ 2024.
- `СТЕНДАП` — отдельного подтверждённого ролика в материалах нет; пока оставить заглушку.

### Карточка `ШОУРИЛ` — утверждено

- Заголовок: `ШОУРИЛ`.
- Подпись: `АДИС В РАБОТЕ · 03:56`.
- Сделать карточку крупнее остальных и использовать её как главный вход в видеоблок.
- На обложке использовать сильный кадр с Адисом и микрофоном, без случайных людей на переднем плане.
- Не запускать видео автоматически со звуком.
- По нажатию открывать полный ролик поверх страницы.
- Позже можно добавить короткое бесшумное превью при наведении.
- Точки-переключатели не использовать: внутри карточки один ролик.
- Не обещать в подписи `разные форматы`: текущий шоурил визуально в основном состоит из свадеб и частных событий.

### Карточка `ЧАСТНЫЕ СОБЫТИЯ` — утверждено

- Основной текст оставить в утверждённой разбивке: `КАМЕРНЫЕ ИСТОРИИ` / `И БОЛЬШИЕ ПОВОДЫ`.
- Категория: `ЧАСТНЫЕ СОБЫТИЯ`.
- Собрать внутри три материала: свадьба на крыше как основная обложка, ещё один свадебный лайв и один день рождения.
- Использовать три точки-переключателя: каждая должна соответствовать реальному материалу.
- Для основной обложки использовать чистый стоп-кадр из ролика про свадьбу на крыше; полный ролик открывать по нажатию.
- Имена Бебуришвили и Люси Чеботиной публично не подписывать до подтверждения Адиса.

### Карточка `КОРПОРАТИВНЫЕ МЕРОПРИЯТИЯ` — утверждено

- Основной текст оставить в утверждённой разбивке: `КОМАНДЫ, БРЕНДЫ И ЗАЛЫ` / `РАЗНОГО МАСШТАБА`.
- Категория: `КОРПОРАТИВНЫЕ МЕРОПРИЯТИЯ`.
- Собрать внутри два материала: мероприятие на 6000 человек как основная обложка и ролик с ПМЭФ / VK Night как второй материал.
- Использовать две точки-переключателя: по одной на каждый реальный материал.
- Вертикальный ролик с ПМЭФ размещать внутри горизонтальной карточки по центру на чёрном фоне, без растягивания и агрессивного обрезания.
- Не публиковать обозначения `6000 ЧЕЛОВЕК`, `ПМЭФ` и `VK NIGHT`, пока Адис не подтвердит точные названия и право использовать брендовые обозначения.

### Карточка `СТЕНДАП` — утверждено

- Основной текст оставить в утверждённой разбивке: `АВТОРСКИЙ МАТЕРИАЛ` / `И ЖИВОЙ ДИАЛОГ С ЗАЛОМ`.
- Категория: `СТЕНДАП`.
- Пока использовать одну аккуратную видеозаглушку формата 16:9 с подписью `ВИДЕО · 60–120 СЕК`.
- До получения реального ролика не показывать точки-переключатели, активную стрелку и фальшивый переход.
- После получения материала добавить настоящую обложку и открытие видео поверх страницы.
- Запросить у Адиса горизонтальный фрагмент сольного стендапа либо разрешённый фрагмент `Открытого микрофона` / Roast Battle: чистый оригинал без чужих водяных знаков.

### Общая кнопка блока — утверждено

- Убрать отдельную белую кнопку `СМОТРЕТЬ`: рабочее видео открывается нажатием на саму карточку.
- Убрать кнопку `ВСЕ ФОТО И ВИДЕО`: сейчас она повторяет смысл карточек и не имеет отдельного понятного назначения.
- Не ставить две белые кнопки подряд под карточками.
- У активных карточек оставить только стрелку. У видеозаглушки стендапа не показывать никакого действия.
- Не связывать публичную медиатеку с кнопкой `МАТЕРИАЛЫ ДЛЯ ОРГАНИЗАТОРОВ`: это разные сценарии.
- Если позже появится отдельная публичная подборка, вернуть кнопку под названием `ОТКРЫТЬ МЕДИАТЕКУ`.

### Нужно уточнить у Адиса

- Является ли текущий шоурил финальной и актуальной версией.
- Можно ли публично использовать лица, имена, бренды и фрагменты частных мероприятий.
- Что именно за бизнес-мероприятие на 6000 человек: бренд, город и год; можно ли публиковать цифру.
- Является ли ролик с ПМЭФ официально `VK Night`; есть ли горизонтальная версия.
- Нужен отдельный горизонтальный стендап-фрагмент 60–120 секунд с точным названием выступления и разрешением на публикацию.

Блок полностью разобран и утверждён: композиция, тексты карточек, реальные материалы, заглушки и логика взаимодействия. Во Framer пока ничего не менять.

## БЕГУЩАЯ СТРОКА ЛОГОТИПОВ

### Движение строки — утверждено

- Один полный проход ряда за `48 секунд`.
- Движение непрерывное, линейное и без ускорений на входе и выходе.
- По краям использовать мягкую маску прозрачности шириной `10–12%` экрана: логотипы должны плавно появляться из темноты и растворяться в ней.
- Не использовать плоские чёрные накладки поверх строки, чтобы на текстурном фоне не появлялись швы.
- Лента не останавливается при наведении.
- Не увеличивать логотипы при наведении, потому что они не являются ссылками.
- Не менять прозрачность при наведении: логотипы не кликабельны, поэтому hover создаёт ложное ощущение ссылки.
- Оставить постоянную прозрачность логотипов `0.78`.
- Оставить две копии ряда для бесшовного цикла и проверить, чтобы один бренд не появлялся дважды одновременно в видимой области.

### Оптические размеры логотипов — утверждено

Все карточки оставить одинаковыми: `240 × 180 px`. Самим логотипам задать индивидуальный масштаб по визуальной массе, а не одну математическую рамку:

- Альфа-Банк — `58 px` по высоте, поднять на `2 px`;
- S7 — `56 px` по высоте;
- BetBoom — `168 px` по ширине;
- Clarins — `190 px` по ширине;
- Kaspersky — `174 px` по ширине;
- LVMH — `180 px` по ширине;
- Фармстандарт — `174 px` по ширине;
- СБЕР — `160 px` по ширине;
- СИБУР — `164 px` по ширине;
- длинный горизонтальный `VK КОНТАКТЕ` — `182 px` по ширине;
- Яндекс — `156 px` по ширине.

После живого просмотра допустимы индивидуальные сдвиги на `1–2 px`, если оптический центр конкретного знака не совпадает с геометрическим.

### Порядок и расстояние — утверждено

- Последовательность: `LVMH → S7 → Kaspersky → Альфа-Банк → Clarins → BetBoom → Яндекс → СБЕР → Фармстандарт → VK → СИБУР`.
- Порядок чередует тонкие надписи, компактные знаки и плотные логотипы, чтобы соседние элементы не спорили по визуальному весу.
- Переход `СИБУР → LVMH` использовать как стык бесшовного повтора.
- Расстояние между карточками: `24 px`.

### Оформление карточек — утверждено

- Размер карточки оставить `240 × 180 px`.
- Фон сделать едва светлее основной секции.
- Использовать тонкую рамку с прозрачностью около `6%` и радиус `10 px`.
- Не использовать тени.
- Обычное состояние логотипа: `opacity 0.78`.
- При наведении логотип не меняет прозрачность.
