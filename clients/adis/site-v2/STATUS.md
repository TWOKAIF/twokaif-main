# Сайт Адиса Маммо — статус

Обновлено: 12 августа 2026.

## Что собрано

- Адаптивная React-версия сайта с отдельной админкой.
- Закреплённая шапка и полноэкранное меню с фото, роллинг-анимацией и социальными ссылками.
- Первый экран с управляемым портретом, красным полем и отдельными настройками композиции для компьютера, iPad и iPhone.
- Блок «// ОБ АДИСЕ» с портретом и утверждённой биографической выжимкой.
- Блок «// ВИДЕО» с двумя Kinescope-видео: «Шоурил 2025» и «Свадебный лайв», плюс две редактируемые заглушки.
- Компактная бегущая строка логотипов с настройками в админке.
- Блок «// ИМЕНА И СОБЫТИЯ»: свадьбы, годовщины, дни рождения и дуэты; добавлены фото Собчак и Урганта.
- Блок «// ФОТО» с галереей, увеличением при наведении и полноэкранным просмотром.
- Контактный блок и футер с материалами для организаторов, социальными ссылками и кнопкой «Наверх».
- Единая система стрелок, ссылок и микроанимаций; добавлены редакционные появления блоков и индикатор прокрутки в шапке.
- Исправлена обрезка крупных заголовков и выравнивание последней sticky-карточки «04 Дуэты».

## Админка

- Разделы: верх сайта, первый экран, об Адисе, видео, бегущая строка.
- Живой предпросмотр компьютера, iPad и iPhone.
- Загрузка портретов через кнопку, черновик и публикация.
- В разделе «Верх сайта» добавлено управление видимостью блоков. Скрытые блоки сохраняют всё наполнение, но исчезают с сайта и из раскрывающегося меню.
- Блок «Имена и события» временно скрыт и в черновике, и в опубликованной версии.
- Проверен production-запуск: сайт и страница `/admin` открываются, закрытые API админки без авторизации возвращают 401.
- Production-сервер доверяет только первому reverse proxy, чтобы защищённая cookie-сессия админки корректно работала за HTTPS/Nginx.
- Для временного показа поисковая индексация запрещена через `robots.txt`, HTML и заголовок Nginx.
- Production CSP разрешает только собственные ресурсы и встроенные Kinescope-видео/постеры.
- Корневой адрес и вложенные страницы production-сборки обслуживаются единым безопасным fallback-маршрутом Express 5.

## Автономная версия

- `npm run build` проходит без ошибок.
- Скрипт `scripts/build-standalone.mjs` собирает один автономный HTML с вшитыми шрифтами и изображениями.
- Готовая копия на Рабочем столе: `Сайт Адиса.html`.
- Для воспроизведения видео в автономной копии нужен интернет, потому что видео размещены на Kinescope.

## Временный прод

- Сайт: `https://adis-stage.twokaif.ru/`.
- Админка: `https://adis-stage.twokaif.ru/admin`.
- Админка закрыта паролем; пароль хранится в связке ключей Mac под именем `Адис Маммо — админка`, в git и на сайте его нет.
- Код хранится в отдельном приватном репозитории GitHub `TWOKAIF/adis-mammo-site`.
- На Aeza работает отдельный сервис `adis-mammo-site.service` на порту `8788`.
- Код развёрнут через `/opt/adis-mammo-site/current`, редактируемые данные и загрузки лежат отдельно в `/opt/adis-mammo-data` и переживают обновление кода.
- HTTPS выпущен через Let's Encrypt с автоматическим продлением.
- Индексация временного адреса запрещена; закрытые API без входа возвращают `401`.
- Проверен реальный вход в админку по HTTPS; опубликованный и черновой блок `Имена и события` скрыты.
